Data for "d-Translated Unit Sensitive Primes

The data on this page is associated with the paper "d-Translated Unit Sensitive Primes" by Thomas Luckner and R. James Philpott. Below is a txt file containing lists associated with the paper. The lists are labeled DTUS[3], DTUS[9], Sier, Ries, DTUScomplete, DTUSBriercomplete, and Brier in this order.

Click here for a text file as described above.

The first 4 of these lists contain lists of the form [r, m, p, k]. The r is the residue of a congruence class used to make a covering system and m is the modulus of the congruence class. For DTUS[3] and DTUS[9], the p is a prime such that the order of 10 modulo p divides m. For Sier and Ries, the p is a prime such that the order of 2 modulo p divides m. For DTUS[3] and DTUS[9], the k is the residue modulo p such that k*10^r+n is congruent to 0 modulo p for n=3 or n=9. For Sier, the k is the residue modulo p such that k*2^r+1 is congruent to 0 modulo p. For Ries, the k is the residue modulo p such that k*2^r-1 is congruent to 0 modulo p.

The next list, DTUScomplete, combines the two lists DTUS[3] and DTUS[9] along with 3 other lists using the op() function found in the software Maple. The first two of the added lists are still in the same form ([r, m, p, k]), but the r and the m are just 0's since these were not used as part of a covering. the third added list is similar, but the covering for n=1 and n=7 are made up of this one congruence class with the prime 3. This table ensures that when applying the Chinese Remainder Theorem for each k and p, the resulting arithmetic progression is made of integers that are d-translated unit sensitve for any nonnegative integer d.

The next list, DTUSBriercomplete, combines all 4 of the first tables making sure to avoid any repeated primes once again using the op() function found in the software Maple. This list ensures that when applying the Chinese Remainder Theorem for each k and p, the resulting arithmetic progression is made of integers that are d-translated unit sensitve for any nonnegative integer d and are Brier numbers.

The last list, Brier, combines the lists Sier and Ries without repeating any primes once again using the op() function found in the software Maple. This list ensures that when applying the Chinese Remainder Theorem for each k and p, the resulting arithmetic progression is made of integers that are Brier numbers.
